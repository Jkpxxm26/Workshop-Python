# Workshop-Python

นี้เป็นWorkshop ที่ผมได้ลองทำพร้อมกับคอร์สเรียนครับ ซึ่งผลงานชิ้นนี้เป็นผลงานไว้สำหรับถามชื่อเมืองหลวงในประเทศต่างๆ(ในชิ้นงานมีประเทศตัวอย่าง3ประเทศ) 
แต่ถ้าเราต้องการเพิ่มข้อมูลเมืองหลวงของประเทศอื่นนอกจากประเทศตัวอย่างได้ครับ
และสิ่งที่ผมได้จากการได้ลงมือทำWorkshop คือการได้ลองประยุกต์โค๊ดด้วยภาษาPythonเบื้องต้นครับ และรวมถึงการสร้างfunctionต่างๆให้สามารถเรียกใช้ซ้ำๆหลายๆครั้งได้ครับ
